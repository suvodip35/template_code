6. **🎮 Web Games & Puzzles**: Tic-Tac-Toe with AI/friend mode, Simon Says memory games, Whack-a-Mole, confetti cannons, and virtual dice rollers.
7. **📝 Form & Input Wizards**: Credit card live formatters, password strength meters, tag cloud filters, and multi-step form progress bars.
8. **💻 Developer Productivity Tools**: Docker compose generators, HTTP status code lookups, Git command cheatsheets, and markdown live previews.
9. **🎧 Media & Audio Visualizers**: Audio frequency visualizers, image comparison sliders, image compressors, and background removers.
10. **🌐 System & Network Tools**: IP address inspectors, ping latency simulators, and webhook testers.

## 🚀 Quick Start (Run Locally in Astro)

### 1. Clone the Repository
```bash
git clone https://github.com/suvodip35/template_code.git
cd template_code
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:4321/](http://localhost:4321/) in your browser.

## 💡 How to Use Any Component in Your Project

Every `.astro` file in this repository is completely **standalone**—no external runtime libraries required:

1. Copy any `.astro` file from this repo into your project's `src/pages/` or `src/components/` directory (e.g., `src/pages/curl-to-fetch.astro`).
2. Ensure you have **Tailwind CSS** installed in your project:
   ```bash
   npx astro add tailwind
   ```
3. That's it! The component is fully functional with responsive layouts, accessible forms, safe clipboard actions, and interactive UI states.
